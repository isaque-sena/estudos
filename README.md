# 🧠 Tracker de Estudos — Isaque Sena

## Como rodar localmente
```bash
pip install streamlit
streamlit run app.py
```

## Como hospedar no Streamlit Cloud
1. Suba no GitHub
2. Acesse share.streamlit.io
3. Selecione o repo e o arquivo app.py
4. Deploy
